# Guarded state values: independent native preregistration

This is a new fixture/model, separate from the sealed J/I/H matrices. No candidate has been executed at this freeze. Production schema is the unique `dragon.guarded-state-values` named metadata string containing `{"hints":[{"function":"oracle","block":"seed","state":"0x2","target":"0x2b"}]}`. Hints predict a same-SSA state and actual target; neither is a fact about memory or program state. Public entry is `guarded-state-values`.

Seven modes: plain, table_before, table_after, freeze, flags, duplicate, tail_call. Each has154 input tuples: base state0/2/50/51/64/all-ones × target43/777/99999 × loop limit0/3 × size519/1024 × two caller layouts (144); state63 with size1023/1024 and state50 with size919/920, target43/limit3/two layouts (8); state2^63 with size65536/limit0/two layouts (2). Total1,078 distinct inputs. No base inputs are removed for the extra boundary tuples.

The header reads fresh state from register offset16 on each iteration. Plain uses add0, freeze keeps an actual freeze, flags keeps `add nuw nsw raw,0`, which is defined for every concrete input. A prior target LOAD value is carried in the loop history PHI; the latch has two actual successor slots to the header. State is never a cycle-dependent inferred constant.

The seed first STOREs state to Guest+32, then executes an unknown external helper exactly once. The helper has only a declaration in analyzed IR; its independently linked C body writes real registers/Guest, increments callcount, changes the state slot to oldState XOR53, and changes the current table cell. The original conditional still uses the old immutable state SSA from before the call. A guard that reloads the state slot is wrong. For initial2, a four-iteration execution alternates2/55/2/55, exercising actual hint hit and miss and both original `state>50` directions. The original branches write different Guest markers and produce different join-PHI bias values, so selecting a wrong direction is observable even on some later bounds failures.

In the overlapping caller layout, regs=Guest+32: the seed STORE aliases register0, and helper Guest+80 aliases register48. Entry x/loop limit and the pre-tail-call side value are actual original SSA snapshots, not assumed ABI preservation. A full64KiB Guest allocation backs every run; logical descriptor sizes restrict the explicit checked target LOAD. The helper takes raw pointers and may legitimately write beyond that logical size while remaining inside allocated storage. All helper effects are compared even when bounds subsequently fail.

The duplicate mode makes BOTH original seed branch slots target small; its root PHI has two equal seed incoming values. The new guard must move both old slots to fallback, append one gate slot, and let inner copying consume only gate. Normal modes use distinct large/small root PHIs and a join PHI. Bounds/state failure paths remain live. The actual target LOAD has seven cases plus default, including repeated good destinations. Table_before/after write777 or99999 before/after that LOAD. tail_call adds a second unknown helper in the proposed copied path and must be rejected without mutation; actual callcount and all effects still execute in the original program.

Two additional normal-equivalence variants run plain with state hint51 or target hint777. These are valid untrusted predictions, not faulty programs: each must preserve full state regardless of whether its prediction matches. The only target decision is based on the actual once-loaded selector; no re-read after a STORE and no inferred immutable table.

Public API13 recipes: normal7; wrongvalue, wrongtarget, resumed, bad metadata, max_blocks3, max_rewrites0 on plain. Normal6 and the two wrong-hint variants must each copy one edge; tail_call stays unchanged. Repeated budget-one invocation must be [1,0,0] with final IR byte-equal to normal. max_blocks3 allows construction of the outer2 blocks but leaves only1 block for the nontrivial inner path, exercising transactional rollback rather than only an early max_blocks1 rejection. Budget/bad/zero outputs must be byte-identical to parsed-before. Every committed copy must be explicit Incomplete. Checks retain module/function/argument/global/metadata identities, seed effects, original conditional fallback, same-SSA target fallback, flags/freeze, and the duplicate incoming slots.

Native scope per build: O0 and O2, before/after seven modes, plus plain wrongvalue/wrongtarget. This is4,928 normal observations: before2,156, changed normal1,848, unchanged tail_call308, wrong-hint616. Repeated build/optimization/API executions are not new samples. Six real faulty programs (double seed CALL, dropped seed STORE, forced wrong original branch direction, stale header state, post-write target reload, wrong join PHI) produce1,848 fault observations. Each fault must match its independently computed faulty reference; every input whose faulty reference differs from normal must be rejected by the normal comparator, with at least one required detection per fault. Each normal frame has11 comparator corruptions,54,208 controls. Total44 gzip streams/6,776 frames per build. A180-second native group timeout remains finite and failures are retained.

Frames compare return8 + callcount8 + the complete73,728-byte arena, including all registers at the actual layout, full64KiB Guest, descriptor/config, all seven Exit fields and other bytes. No normalization, exclusions or skipped cases. Successful business returns and checked failures are reported separately. Saved streams receive exact file-set/length/EOF and reference-model replay audits. Runtime/source hashes before and after and actual loader paths bind each build. No candidate execution, native success or complete real-loop closure is claimed by this preregistration.

The implementation author has confirmed these shapes are within the intended domain, including safe flags and duplicate seed slots; that review is not semantic evidence. The native model is sequential byte-array logic, independent of the implementation's path discovery or guard construction. Explicit poison/undef and cyclic proofs remain structural refusal cases, not concrete native inputs. Real ELF closure audits must separately account for the new state guard while preserving the original target-only metric; this fixture cannot establish real-loop closure.
